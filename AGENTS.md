# awesome-programmatic-ttrpg Agent Instructions

## Scope

This project is a curated awesome-list style repository for builders of
programmable tabletop RPG software.

## Read Order

1. `CLAUDE.md`
2. `README.md`

## Rules

- Keep the list focused on reusable, code-first TTRPG software.
- Prefer live GitHub metadata when adding or removing entries.
- Favor repositories that are open source, active enough to be useful, or
  historically important to the ecosystem.
- Avoid list spam: small personal experiments are fine only if they are clearly
  interesting to developers.
